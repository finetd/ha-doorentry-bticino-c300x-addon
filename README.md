# Door Entry BTicino C300X — Add-on per Home Assistant

Repository di **add-on** per Home Assistant. Porta il videocitofono BTicino/Legrand Classe 300X
(app *Door Entry*) in Home Assistant, senza root e senza modificare il citofono.

## Installazione del repository
1. Home Assistant → Impostazioni → **Add-on** → Add-on Store.
2. Menu ⋮ in alto a destra → **Repository** → incolla:
   `https://github.com/finetd/ha-doorentry-bticino-c300x-addon`
3. Compare l'add-on **Door Entry BTicino C300X**: installalo e configuralo (email/password Door Entry).

Per le entità in Home Assistant serve anche l'**integrazione** (repository separato, via HACS):
`https://github.com/finetd/ha-doorentry-bticino-c300x`
